# Simiso

IT student building Android and ASP.NET Core apps, plus small web tools for study and personal finance.

## What I work with

- **Mobile:** Kotlin, Android, Room, SQLite
- **Web:** C#, ASP.NET Core MVC, HTML, CSS, JavaScript
- **Data:** SQL Server, local databases

## Projects

### [Ledger Lite](https://github.com/Simiso01/ledger-lite)

A browser expense tracker in rand. Add income and expenses, set a monthly budget, and keep everything in the browser. No account and no server.

### [Module Board](https://github.com/Simiso01/module-board)

A study board for modules and tasks. See what is waiting, what is in progress, and what is done.

### [Session Log](https://github.com/Simiso01/session-log)

A study timer with a weekly log. Start a session for a module, or add the minutes by hand.

### [CashTrack](https://github.com/Simiso01/CashTrack)

An Android personal-finance app. It covers expenses, categories, monthly goals, and a dashboard, with data stored on the device in Room.
